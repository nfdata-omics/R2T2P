# nfdata-omics/r2t2p: Documentation

The nfdata-omics/r2t2p documentation is split into the following pages:

- [Usage](usage.md)
  - An overview of how the pipeline works, how to run it and a description of all of the different command-line flags.
- [Workflow rationale](workflow.md)
  - A conceptual overview of why the pipeline is organized around RNA-seq-guided annotation refinement,
    Ribo-seq ORF discovery, and proteomics integration.
- [Output](output.md)
  - An overview of the different results produced by the pipeline and how to interpret them.
